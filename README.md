# 点亮暨南 · 三地五校，共此星光

Vue 3 + TypeScript + Vite + Three.js 纯前端互动作品。访问石牌、番禺、广园东、珠海、深圳五个校区，阅读地标历史，然后观看多校区灯光巡游与星空庆生。

## 启动

使用 Node.js 22.12+，建议 Node.js 24。文本文件统一 UTF-8。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。默认端口为 5173，端口被占用时 Vite 自动顺延；本轮开发服务使用 **http://127.0.0.1:5175**。

```powershell
npm test          # Node 纯逻辑检查，不打开浏览器
npm run build     # Vue / TypeScript 检查和生产构建
npm run preview   # 通过 HTTP 预览 dist
```

`dist/` 可部署到静态服务器的根目录或子目录，不支持直接双击 HTML。运行不需要地图 API Key、外部字体、后端或数据库。校史来源链接由用户点击后打开。

## 探索与演出

- 开场是三地五校区域地图。点击地图标签或底部五校按钮进入对应校园；每次进入都回到该校区白天鸟瞰。
- 左键拖动旋转、滚轮缩放、右键平移；手机单指旋转，双指缩放和平移。提供归位、缩放和昼夜按钮。
- 点击重要地标建筑、空间标签或左侧地标列表，镜头靠近并显示历史介绍及校方出处。建筑遮挡或距离过远时隐藏空间标签，HTML 列表始终可用。
- 访问记录、已读地标在本地保存，重复点击不会重复计数。旧版深圳点亮进度仅迁移为“已访问深圳”，不会提前解锁其余四校。
- 首次访问满五校后约 2.6 秒自动开始庆生。可点“先继续探索”或任一地标取消自动开始，随后通过“开启星空庆典”主动开始。恢复已完成记录时不自动播放。
- 演出可暂停、返回地图和重播；Esc 取消倒计时或退出演出。重置会清空五校访问和历史阅读记录。

正常演出约 **76 秒**，计时在后台标签页中暂停：

| 时间 | 画面 |
| --- | --- |
| 0–30 秒 | 石牌 → 番禺 → 广园东 → 珠海 → 深圳，每校 6 秒，镜头环绕、窗光和路灯渐亮 |
| 30–37 秒 | 从深圳拉远，五校建筑微缩落在区域地图上，保留片刻全景 |
| 37–41 秒 | 镜头由区域地图转向星空 |
| 41–47 秒 | 星光聚成金色大字「120」，下方标记 1906—2026 |
| 47–53 秒 | 同一批星光变成官方蓝绿色校徽 |
| 53–60 秒 | 星光变成三层蛋糕，浮现带校徽、蓝绿色缎带、金色 120 和烛光的立体蛋糕 |
| 60–66 秒 | 星光变成「暨南大学 / 生日快乐」 |
| 66–76 秒 | 祝福保留，金色、青蓝、紫红烟花在两侧绽放 |
| 76 秒后 | 停留祝福画面，可重播或回到校园自由观察 |

巡游字幕由当前镜头的校区标识同步驱动：上方显示校区名，下方显示“四字＋四字”原创宣传语。石牌“薪火相传，弦歌不辍”、番禺“笃学求新，智启未来”、广园东“华文为桥，声教四海”、珠海“山海逐梦，扬帆致远”、深圳“敢闯敢创，勇立潮头”。这些是作品文案，不作为官方校训引用。

系统启用“减少动态效果”时，每校和每章节保留 2 秒，总计 24 秒；采用静态切换，关闭环绕、粒子飞行、闪烁与烟花爆发。偏好在每次演出开始时采样，避免中途切换偏好导致章节跳跃。默认不播放音乐。

## 建模依据与边界

五校分别对照本地保存的卫星影像手工标定可见屋顶、道路、水体与运动场，采用真正的三维几何体，没有用卫星图片平铺代替建筑。

- **深圳**：保留详细的阶梯综合楼、弧形玻璃翼楼、五组宿舍、英东体育中心折面屋顶、南门和广场；另用校方实景与用户概念图核对立面。
- **石牌**：包含北部密集住宿区、东西向道路、明湖、体育馆与蓝紫色跑道，辅以校方校园导览图定位。
- **番禺**：包含斜向建筑轴线、惠全楼、裕华堂、弯曲湖岸、宿舍与东西两处运动场。
- **广园东**：包含红褐屋顶教学区、运动场、南部建筑及西侧山林。
- **珠海**：包含教学综合楼、北侧圆形建筑、日月湖、运动场和东侧住宿区与山林。

其余四校立面采用带重复窗格、楼层线、屋顶设备的参数化模型，细节密度低于深圳。仅番禺图书馆地上六层等取得官方信息的特征据实采用；其他楼高、窗格数量、背面和地形起伏属于推断。没有制作室内、测绘尺寸、完整校园外围，也没有把卫星影像未知的拍摄日期当作当前实况。因此这是**有卫星布局依据的校园外观模型，不能称为测绘级 1∶1 复刻**。

区域地图表达校区相对地理位置；展示用校园微缩比例与底图不同，广州三个校区的标签使用引导线错开。校徽使用官方原始素材，白天中性光照，夜晚以蓝绿色与暖金灯光搭配。[详细资料与标定记录](references/SOURCES.md)。

## 本轮检查与人工验收

已通过 `npm test` 的 8 项纯逻辑检查及 `npm run build`。Three.js 核心分包约 636 KB，Vite 有大于 500 KB 的体积提示，构建成功。

按要求**未进行浏览器运行检查、截图比对或前端自动化验证**。请自行验收：

1. 打开五校地图，确认五个标签及底部入口可用；分别进入校园，与 `references/satellite-*.jpg` 比较主体位置、建筑朝向、湖岸、跑道及颜色。
2. 每校拖动、缩放、平移与归位，检查建筑立面、近景和低角度地形；拖动结束不应触发地标点击。
3. 点击建筑、标签和左侧地标列表，确认历史卡、镜头与来源链接对应。旋转到建筑背后时，空间标签应被遮挡隐藏。
4. 访问两校后刷新，确认进度保留；重复访问不增加计数。五个校区全部访问后自动开始演出；取消倒计时后可以继续探索并手动开始。
5. 按上表观看完整演出，检查多校亮灯、地图五个亮点、星空大字、校徽、带校徽的立体蛋糕及烟花顺序；确认「120」和生日祝福清楚，宽屏和竖屏均无主要内容裁切。
6. 演出中暂停、继续、切换浏览器标签页、按 Esc，结束后重播；再次进入校园应恢复自由操作。
7. 测试昼夜按钮、Tab / Enter、系统减少动态效果、移动端手势和尺寸变化。没有 WebGL 或资源加载失败时应显示可重试提示，图形上下文恢复后可以继续。
8. 点击“重新出发”，确认访问/已读清空且演出重新锁定；禁用本地存储时确认提示显示、当次探索仍可完成。

## 修改入口

| 文件 | 用途 |
| --- | --- |
| `src/campuses.ts` | 五校配置、历史及出处、地图坐标、访问与阅读进度 |
| `src/campus-plans.ts` | 石牌、番禺、广园东、珠海卫星手描布局 |
| `src/campus-models.ts` | 四校参数化几何、植被和灯光，接入深圳模型 |
| `src/model.ts` / `src/campus.ts` | 深圳详细模型及照片朝向的局部坐标 |
| `src/regional-map.ts` | 区域轮廓、五校亮点和引导线 |
| `src/scene.ts` | 渲染、轨道控制、镜头导演、拾取、标签、资源释放 |
| `src/show-timeline.ts` | 可独立检查的演出时序 |
| `src/star-show.ts` | 星光变形、官方校徽采样、立体主题蛋糕和烟花 |
| `src/App.vue` / `src/style.css` | 界面、历史卡、访问流程及响应式样式 |

资源释放包括模型、纹理、实例化缓冲、后处理、监听器与 ResizeObserver。树木使用实例化，静态建筑按材质合并，移动端减少植被/粒子并关闭阴影，限制渲染像素比。
